 AutoSalon Database Management System 

Проект базы данных для управления автосалоном (учёт автомобилей, клиентов, сотрудников, услуг и заказов).

Технологии
- СУБД: MySQL / MariaDB (XAMPP)
- Инструменты: phpMyAdmin

Структура базы данных
База данных содержит следующие основные таблицы:
 `cars` — автомобили в наличии (марка, модель, цена, статус);
 `clients` — информация о клиентах;
 `employees` — сотрудники автосалона;
 `services` — предоставляемые услуги и сервисное обслуживание;
 `orders` — заказы и продажи.

 Как развернуть базу данных локально
1. Запустите MySQL в XAMPP Control Panel.
2. Перейдите в phpMyAdmin (`http://localhost/phpmyadmin`).
3. Создайте новую базу данных с именем `autosalon`.
4. Перейдите во вкладку Import и выберите файл `autosalon.sql` из этого репозитория.
5. Нажмите Go для выполнения скрипта.
